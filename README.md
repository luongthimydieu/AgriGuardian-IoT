# 🌱 AgriGuardian-IoT

能量自给型无线农业墒情监测网络 | 国家级大学生创新创业训练计划项目

## 📌 项目简介

AgriGuardian-IoT 是一套面向智慧农业的零维护、自供电、智能化土壤墒情监测解决方案。针对传统农业传感器"频繁换电池、布线成本高"的核心痛点，通过多源能量收集与边缘智能技术，实现7×24小时无人值守的长期监测与干旱预警。

### 核心指标：
 
**☀️ 续航时间：连续阴雨天工作 >14 天**
 
**📡 网络容量：单网关支持 50+ 监测节点**
 
**🎯 预测精度：土壤墒情预测误差 <8%**
 
**⚡ 系统功耗：休眠电流 <1μA**

┌───┬───┬───┬───┬───┬───┬───┬───┬───┬───┬───┬───┬───┬────┬────┐

## 🚀 核心创新点

- 事件驱动型能量管理中间件：基于MSP430铁电存储技术，实现"能量充足实时传、能量匮乏本地存"的自适应策略，较传统周期上报节能60%
 
- 土壤墒情-气象耦合预测模型：融合公开天气数据与本地传感器时序，轻量化XGBoost模型在云端实现48小时干旱预警，准确率>85%
 
- LoRaWAN混合MAC协议：自主研发CSMA/CA与TDMA动态切换机制，支持50节点大规模组网，丢包率<5%
 
- 全链路自动化运维：基于GitHub Actions实现"代码提交→固件编译→OTA升级→集成测试"的CI/CD流水线
